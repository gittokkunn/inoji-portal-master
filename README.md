# inoji-portal-master

個人用アプリ「イノジポータル」が、マスタ(グループ・メンバー・作品・盤・収録曲・曲・応募企画)を更新するために取りに行く、公開の静的ファイルです。

- `index.json` … 索引(形式の版・マスタの版・本体のファイル名・大きさ)
- `master-<版>.json` … 本体

データは、公式サイトの公開ページから集めた事実(名前・作品名・発売日・品番・価格・収録曲・公演やイベントの日程・応募期間など)です。**公式の情報ではなく、誤りを含むことがあります。**
作り方は、アプリ側の `tool/master/` にあります。取りに行くだけ(GET)で、アプリは端末の情報を何も送りません。
